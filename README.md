# سورپرایز تولد 🎂 — راهنمای دارایی‌ها و استقرار

یک وب‌اپ کامل، فارسی، راست‌به‌چپ و موبایل‌محور با HTML/CSS/JS خالص.
همه‌چیز در یک فایل `index.html` است. جای استیکرها و ویدیو فعلاً خالی/placeholder
است و بدون آن‌ها هم سایت درست کار می‌کند (fallback نمایش داده می‌شود).

## ۱) جای فایل‌ها (Asset guide)

فایل‌هایت را دقیقاً در این مسیرها بگذار؛ نام‌ها را می‌توانی عوض کنی،
فقط باید با مقدارهای داخل آبجکت `ASSETS` در `index.html` (تگ `<script>`) یکی باشد.

```
web/
├── index.html
└── assets/
    ├── stickers/
    │   ├── hello.png         ← صحنه ۱ (سلام)
    │   ├── thinking.png      ← صحنه ۲ و ۳ (فکر، دست زیر چانه)
    │   ├── confused.png      ← (آماده برای استفاده در آینده)
    │   ├── explaining.png    ← صحنه ۳، گزینه A (توضیحی/ناراحت بامزه)
    │   ├── proud.png         ← صحنه ۳، گزینه B (مفخر)
    │   ├── encouraging.png   ← صحنه ۴ (تشویق، قبل از آرزو)
    │   └── celebrating.png   ← صحنه ۵ (ذوق‌زده)
    ├── gifts/
    │   ├── gift1.png          ← صحنه ۵ب (تصویر داخل کادوی اول)
    │   └── gift2.png          ← صحنه ۵ب (تصویر داخل کادوی دوم)
    ├── vidu-video-3510148997296306.mp4  ← صحنه ۶ (ویدیوی ~۱۰ ثانیه / کادوی اصلی)
    ├── music/
    │   └── Talk Down & Fedi - Dafi Surprise.mp3  ← آهنگ پس‌زمینه (از صحنهٔ کیک به بعد، حلقه‌ای، بدون کنترل)
    └── video-poster.jpg       ← اختیاری (تصویر کاور ویدیو)
```

- فرمت پیشنهادی استیکر: PNG شفاف (transparent)، مثلاً ۵۱۲×۵۱۲.
- اگر فایلی نبود، سایت نمی‌شکند: جایش یک ایموجی/باکس ملایم نمایش داده می‌شود.
- برای تغییر مسیرها، فقط همین بخش را ویرایش کن:

```js
const ASSETS = {
  stickers: { hello: 'assets/stickers/hello.png', ... },
  gifts:    [ 'assets/gifts/gift1.png', 'assets/gifts/gift2.png' ],
  video:    { src: 'assets/vidu-video-3510148997296306.mp4', poster: '' },
};
```

## ۲) متن‌ها

تمام دیالوگ‌ها داخل خود `index.html` هستند و مستقیم قابل ویرایش‌اند
(هر صحنه با کامنت `SCENE n` علامت‌گذاری شده). اعداد فارسی هم به‌صورت فارسی
نمایش داده می‌شوند (مثلاً شمارش معکوس ۵ تا ۱).

## ۳) تست روی کامپیوتر

هر روشی که فایل را از طریق `http` سرو کند:

```bash
# با Python
python -m http.server 8000
# سپس در مرورگر:  http://localhost:8000

# یا با Node
npx serve .
```

نکته: صفحه را در حالت موبایل مرورگر (Device Toolbar) هم چک کن.
دکمهٔ «فوت کن!» همیشه کار می‌کند؛ گزینهٔ میکروفون اختیاری است و
فقط با کلیک روی آن دسترسی میکروفون درخواست می‌شود.

## ۴) استقرار روی هاست ایستا (Static hosting)

چون فقط فایل‌های استاتیک داری، هر میزبان ایستایی جواب می‌دهد:

- **GitHub Pages**: مخزن بساز، فایل‌ها را push کن، از Settings → Pages فعالش کن.
- **Netlify**: پوشهٔ `web` را روی app.netlify.com بکش‌ورها (drag & drop) کن.
- **Vercel**: `vercel` از CLI یا import از گیت‌هاب.
- **Cloudflare Pages**: اتصال مخزن یا آپلود مستقیم.

مسیر `assets/...` نسبی است؛ اگر همه‌چیز را در ریشهٔ سایت آپلود کنی
(`index.html` + پوشهٔ `assets`) بدون تغییر کار می‌کند.

## ۵) بررسی‌های انجام‌شده

- بدون React/Vue/بیلد/بک‌اند؛ یک فایل.
- RTL و تایپوگرافی فارسی (Vazirmatn با fallback).
- بدون اسکرول افقی؛ موبایل‌اول و ریسپانسیو.
- صحنه‌ها بدون reload صفحه عوض می‌شوند؛ محافظت در برابر دابل‌کلیک.
- کیک با دقیقاً ۱۷ شمع روشن + عدد ۱۷؛ شمارش معکوس فقط بعد از کلیک.
- احترام به `prefers-reduced-motion`.
